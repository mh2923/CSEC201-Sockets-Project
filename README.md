# CSEC201-Sockets-Project
CSEC-201 Remote File Management Protocol (RFMP) project using Python socket programming and a C client.

RFMP (Remote File Management Protocol) lets a client manage files and folders on a server over TCP sockets.

**Files**
- `Usman_client.py`: Python client
- `Yerkebulan_server.py`: Python server
- `Izhan_protocol.py`: packet definitions shared by the client and server

**Packet types**
- SS: start
- CC: confirm connection
- EC: encryption
- CM: command
- DP: data
- SC: successful
- EE: exception
- End: closing
